Ember Cloister — bspharness architectural reference area

Generated by bspharness for Tim Bergeron.
Repository: https://github.com/timbergeron/bspharness

Two-level gallery, arcade, stair landing, vaulted nave, entry arch,
raised apse, sky lantern, and visible lighting fixtures.
This area has four pickups and is not a finished gameplay map.

Textures and original Quake game assets: id Software.
Stock textures extracted locally from the owner's original pak0/pak1.
No PAK or WAD is included. No Makkon assets are used.
Compilers: ericw-tools; engine verification: QSS-M.

Install maps/reference_hall.bsp and maps/reference_hall.lit in a Quake
gamedir's maps directory, preserving the same basename for colored light.
Launch with: map reference_hall

Regenerate with examples/reference_hall.py and your local stock WAD.
See docs/REFERENCE_HALL.md for budgets, cameras, and movement probes.
