BSP Harness material diagnostic map
Generator: examples/materials.py

Original procedural tile and brick textures: bspharness.
Original utility and trim textures: bspharness.
Map generation and material alignment: bspharness.
Compilation: ericw-tools (see build.json for exact compiler hashes).
Quake game data and engine are supplied separately by the player.

This is a material-system diagnostic, not a finished gameplay map.
It demonstrates matching 64px/128px floor repeats, wrapped brick walls,
and automatic doorway frames with flush floor borders. Texture artwork,
lighting, undeclared trim corners, and movement require visual review.
No Makkon textures or original Quake game files are included in this ZIP.
