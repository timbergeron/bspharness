Keep local WAD2 texture libraries here. `*.wad` files are ignored by Git.

Generate `blockout.wad` with `python3 -m bspharness blockout-wad assets/wads/blockout.wad`.
Extract stock `id1.wad` from your own PAKs with the README's `id-wad` command.
See [texture sources](../../docs/TEXTURES.md) for other libraries.

Preserve downloaded pack readmes and credits locally. No Makkon assets are
part of the harness for now.
